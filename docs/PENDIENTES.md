# Pendientes de este scaffold

Este proyecto se generó como una base funcional y verificada (backend probado con pytest,
frontend validado sintácticamente). Antes de producción, revisa:

1. **manual_usuario.pdf / manual_tecnico.pdf / presentacion.pptx**: no se generaron con contenido
   real porque requieren capturas de pantalla y contenido específico de tu app. Pídeme que te
   los cree cuando tengas la app corriendo.
2. **screenshots/**: agrega capturas reales una vez que pruebes la app.
3. **Fuentes Poppins**: agrega los .ttf reales (ver assets/fonts/LEEME.md).
4. **SECRET_KEY**: cambia la clave en backend/.env antes de desplegar a producción.
5. **deploy/.env.production**: completa con tus credenciales reales de producción (no subir a git).
